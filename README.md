# docs

Documentation for Sankarasanjeevi's Premiere Pro and After Effects extensions, built with
[Astro Starlight](https://starlight.astro.build) and published to
https://sankarasanjeevi.github.io/docs/ by the GitHub Actions workflow on every push to `main`.

Renamed from `toolninja-docs` on 2026-10-10. A separate redirect-only repo named
`toolninja-docs` keeps every old link working.

```
npm install
npm run dev      # local preview
npm run build    # output in dist/
```
