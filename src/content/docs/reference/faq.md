## Does Subtext generate captions or transcribe audio?

No — Subtext **edits caption files you already have** (from Premiere's speech-to-text, a transcription service, or anywhere else that gives you an SRT). It makes fixing them fast.

## Does it work on Mac?

**Yes** — Subtext runs on both Windows and macOS. The other extensions are Windows-only for
now; each tool's overview page states its requirements.

## Which Premiere versions are supported?

**Premiere Pro 2023 through 2026** (CEP panel, v23.0+). Tested on Premiere Pro 2026.

## Is it a subscription?

No. **One-time purchase, yours forever** (see the EULA for update terms).

## How many computers can I install it on?

**Up to 2 computers** that you personally use — one license per person. Replaced a machine and hit the limit? Email support and I'll reset it. See [Activating your license](/docs/getting-started/licensing/).

## The installer says "self-signed" — is that safe?

Yes, that's **normal for independent Premiere extensions** — it means the package is signed by an independent developer rather than by Adobe. The included install guide walks you through it. See [Installing an extension](/docs/getting-started/installation/).
