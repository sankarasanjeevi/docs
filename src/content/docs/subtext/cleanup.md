---
title: Cleanup
description: Fix an entire caption file in one pass with Subtext's cleanup bar.
---

The **cleanup bar** fixes common problems across the **whole file** in a single pass. Every cleanup action is undoable, so you can try one and back it out if it isn't what you wanted.

## Cleanup actions

- **Remove gaps** — close the empty time between captions.
- **Remove line breaks** — flatten multi-line captions into single lines.
- **Remove punctuation** — strip punctuation across every caption at once.

Each runs across all captions in the file, not just the selected line.

:::tip
Cleanup is a great first step right after importing a rough auto-generated SRT — remove line breaks and punctuation, then do your word-level fixes on clean text.
:::

## Undo

All cleanup actions are undoable with **Ctrl+Z**, so a whole-file change is never a one-way door.
